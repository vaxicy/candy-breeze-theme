轻盈、甜美、清新的粉彩 VS Code 主题，包含 **Candy Breeze Light** 与 **Candy Breeze Dark** 两款变体。糖果粉、冰蓝、薄荷绿、奶油黄四色交织，让编辑器界面既温柔又有呼吸感。

A sweet, airy pastel VS Code theme with **Candy Breeze Light** and **Candy Breeze Dark** variants, blending candy pink, ice blue, mint and butter yellow for a gentle, breathable editor.

## ✨ 特性 / Features

- 两款主题：浅色 Candy Breeze Light 与深色 Candy Breeze Dark，一键切换。
- Two variants: light "Candy Breeze Light" and dark "Candy Breeze Dark", switchable in one keystroke.
- 覆盖编辑器、侧边栏、状态栏、标签页、终端等核心 UI 配色。
- Full coverage of editor, sidebar, status bar, tabs and terminal UI colors.
- 语法高亮与语义高亮配套调校，浅色版使用加深色阶保证可读性。
- Tuned syntax and semantic token colors; the light variant uses deepened shades for readability.
- 糖果粉主色统一贯穿强调色、选中与悬停态，视觉风格一致。
- Consistent candy-pink accent across selections, hover and highlights.

## 📦 安装 / Installation

**方式一 · 从 VSIX 安装 / From VSIX**
1. 打开命令面板（`Ctrl+Shift+P`），运行 `Extensions: Install from VSIX...`。
2. 选择本项目下的 `candy-breeze-theme-1.0.0.vsix`。
3. 按 `Ctrl+K Ctrl+T`，搜索并选择 `Candy Breeze Light` 或 `Candy Breeze Dark`。

**方式二 · 从 Marketplace 安装 / From Marketplace**
1. 在 VS Code 扩展面板搜索 `Candy Breeze Theme`。
2. 点击安装，随后按 `Ctrl+K Ctrl+T` 切换主题。

## 🛠 开发 / Development

在 VS Code 中打开本文件夹，按 `F5` 启动扩展开发宿主（Extension Development Host），在新窗口的 `Ctrl+K Ctrl+T` 中选择 Candy Breeze 主题即可实时预览。

Open this folder in VS Code and press `F5` to launch the Extension Development Host; pick a Candy Breeze theme from `Ctrl+K Ctrl+T` to preview live.
